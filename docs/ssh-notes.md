# SSH Notes

## SSH (Secure Shell)

SSH is a protocol that is used to access and communicate securely with a remote computer over a network. 

- It uses a client-server model
- The communication is encrypted
- It is commonly used for remote terminal access
- Uses TCP port 22 as the default

## SSH Client

The program that starts an SSH connection to a remote machine. 

Example: `ssh username@server-ip`

## SSH Server

The software on the remote machine that accepts and handles SSH connections.

## sshd (SSH Daemon)

The SSH server program that runs in the background on the remote machine and handles incoming SSH connections.

- ssh: client program that starts the SSH connection
- sshd: server daemon that accepts and handles the incoming SSH connections
- SSH: the protocol that they use to communicate securely

## Authentication

The process of verifying the identity of a user who is trying to access the server. SSH can authenticate users using methods such as passwords or SSH keys.

## SSH Authentication Event

A record of authentication activity produced when someone tries to authenticate through SSH.

Examples include:
- Successful login attempts
- Failed login attempts
- The username involved
- The source IP address

## systemd-journald

A Linux service that collects and stores log messages generated by the system and its services. SSH authentication activity from sshd can be recorded by the Linux logging system. It is a daemon that runs in the background on Linux.

## Journal

The system log data that is collected by systemd-journald and it can contain events from many different Linux services, not only SSH.

## journalctl

A command used to view and search logs stored in the systemd journal and it can be used to inspect SSH-related events recorded on the server.
