# SSH Notes

## SSH (Secure Shell)

SSH is a protocol that is used to access and communicate securely with a remote computer over a network. 

- It uses a client-server model
- The communication is encrypted
- It is commonly used for remote terminal access
- Uses TCP port 22 as the default

## SSH Client

The program that starts an SSH connection to a remote machine. 

Example: `ssh username@server-ip`

## SSH Server

The remote machine that accepts the SSH connections.
